# 角取り陣

▶ **あそぶ：https://ryowatanabe1161-svg.github.io/kakutori-jin/**


角と角でつなぐ、4色・20×20の陣取りパズル（オンライン対戦）。クラシックな「角でつなぐポリオミノ配置ゲーム」の公式ルールに沿ったオリジナル作品です。

- 盤20×20、4色（藍＝左上・山吹＝右上・紅＝右下・若竹＝左下）。各色1〜5マスの21ピース（89マス）。
- 最初のピースは自分のスタートの角をおおう。以降は自分の色と**角だけ**で接し、**辺では接しない**。ほかの色とは辺で接してもOK。回転・裏返しOK。
- 置けなくなったらパス（以後その色は置けない）。全員置けなくなったら終了。
- 得点：残りマス×−1。全部置いたら+15、最後が1マスのピースなら+20。
- 人間1〜4人。空いた色は ふーさん🐻（弱い／普通／強い／アストラウルトラ😎）。2人なら「1人2色」も選べる。アストラウルトラがいると開始時に「ふーさん🐻覚醒」演出。

## 構成
PeerJS（WebRTC P2P）、ホストのブラウザが進行・合法手チェック・CPU思考を担当。部屋コード・招待URL・QR、ニックネームで再接続。切断した人の手番は、ホストが「ふーさんに代打ち」を頼めます（戻ったら自動で返却）。

- `index.html` 画面・スタイル・覚醒演出 / `app.js` 通信・進行・盤UI / `logic.js` ルール・合法手・得点・CPU / `config.js` ICE設定
